## 1. ひとことで言うと

Actify は、**大学受験生の毎日の自習を、担当の講師（コーチ）が週ごとに計画して見守る、学習管理のWebサービス**。

- 生徒は、自分が勉強できる時間を週ごとにカレンダーへ登録する。
- 講師は、その時間の中に「どの参考書のどの範囲を何分やるか」を入れていく。小テスト（問題と解答のPDF）は自動で付く。
- 生徒は、その日の予定を上から順にやって、点数と一言を返す。
- 点数から再テストの時期が決まり、参考書が志望校の入試までに間に合うかが見える。
- 運営は、参考書（教材）とアカウントを管理する。
- 生徒の画面には、受験AIのキャラクター「Actifyくん」が常にいて、相談に乗ったり画面を歩き回ったりする。

ロゴのキャッチコピーは「**学びを、動かす。**」（ロゴの一部なので消さない）。

## 2. 背景と目的

### 2.1 誰が作っているか
- 依頼者は moment株式会社 の代表。このモックは、依頼者が受け取った最初のモック（別のAIが「構想書」をもとに作った v1）を、依頼者の指摘に沿って作り直し続けているもの。
- 構想書そのものは手元に無い（**不明**）。v1 の README に「構想書のMVPをもとに作成」とある。

### 2.2 解きたい問題（依頼者の指摘から読み取れること）
1. **入力が多すぎて続かない。** v1 は構想書の項目を全部フォームにしていて、生徒はタスク1件ごとに5項目、講師は7項目を手で入れる作りだった。
2. **講師の計画づくりが大変。** 生徒ごとに、空いている時間・参考書の進み・再テストの時期・小テストの版を見比べて予定を組む必要がある。
3. **同じ小テストを同じ生徒に二度配ってしまう。** 版の管理が手作業だと重複する。
4. **受験生にとって一番大事な「参考書が入試までに終わるか」が見えにくい。**
5. **生徒の様子（つまずき・感想）が講師に届かない。**

### 2.3 目的（このサービスで実現したいこと）
- 生徒は「見る → やる → 完了」だけで毎日が回る。手で入れる数字は点数だけ。
- 講師は、生徒の空き時間に合わせて、少ない操作で1週間の計画を組める。おすすめは使いたいときだけ使える。
- 小テストは「その生徒がまだ使っていない版」が自動で付き、二度配られない。
- 参考書ごとに、入試・目標日までに1周終わるペースかどうかが一目で分かる。
- 生徒の一言が講師の計画画面にそのまま届き、講師は返信できる。
- AIキャラクターで、一人で勉強する受験生が続けやすくなる。

### 2.4 想定している利用者
| 役割 | どんな人か | 主に使う端末（想定） |
| --- | --- | --- |
| 生徒 | 大学受験を控えた高校生（デモは高2〜高3） | スマホが中心 |
| 講師（コーチ） | 生徒を数人〜担当し、週ごとに計画を立てて面談する人 | パソコン中心（スマホでも使える） |
| 運営 | 教材とアカウントを管理する事業者側の人 | パソコン |

※ 料金・契約形態・対象の塾や個別指導の形態・販売方法は **不明**。

## 4. 生徒の機能

### 4.1 ホーム
- あいさつと今日の状況（「今日の予定は3件、のこり2件です」。0件の日は「今日は先生が入れた予定がありません」）。
- 上の数字2つ：**今日の勉強時間**（何件中何件完了）／**志望校まであと何日**（押すと目標・プロフィール）。
- **次の予定**（いちばん大きい枠）：教材名・範囲・時刻・長さ・小テストの満点。
  - 「始める」でタイマー開始。「もう終わった」ですぐ完了の画面へ。
  - 小テストが付いていれば「問題を開く」「解答を開く」（PDF）。
  - タイマーは**時計の文字盤の形**。色の部分が残り時間（1周60分、予定が60分を超えるときは120分）。予定を過ぎると「+○分 オーバー」。一時停止・再開・タイマーをやめる、ができる。止めていた時間は勉強時間に数えない。
- 点数がまだの完了済みタスクがあれば「点数を入れる」。
- **今日のほかの予定**：時刻・教材・範囲・長さ。左の丸を押すと完了。
- **やり残し**（過去の未完了）：「先生が次の予定に組み直します」。
- 予備時間の予定には「やり残しを入れる」ボタン（いちばん古いやり残しをその時間に入れる）。
- 右側（スマホでは下）：参考書の進み（棒）／今週の勉強時間（曜日ごとの棒）／担当コーチ（次の面談・コーチからのメッセージ）。

### 4.2 タスクの完了
- 完了の画面で入れるのは2つだけ：
  1. **点数**（小テスト付きのときだけ。＋−ボタンあり。満点はPDFの登録時の値。あとで入れてもよい）
  2. **ひとこと**（任意）：「かんたん／ちょうどいい／むずかしい／時間が足りない」から1つ＋自由な一言（80字まで）。講師に届く。
- 勉強時間はタイマーの計測。タイマーを使わなければ予定の時間。「始める」から5分未満で完了したら押し間違いとみなし、予定の時間で記録。
- 完了すると Actifyくんがお祝いし（点数で喜び方が変わる）、通知に「取り消す」が出る。
- 完了したタスクは「未完了に戻す」「点数・ひとことを直す」ができる。

### 4.3 予定（週カレンダー）
- 週ごとのカレンダー（6:00〜24:00）。前の週・次の週へ移れる。パソコンは7日、スマホは3日ぶんが入る幅で今日の列から。
- **勉強できる時間**を生徒が登録する（薄い緑の背景）。
  - なぞって塗る（スマホは押すと1時間）か、「時間を追加」から日にち・始まり・終わりを選ぶ。
  - 登録は**その週だけ**が基本。毎週にしたい枠だけ「毎週くり返す」をオンにする。
  - 先週と同じなら「先週と同じにする」で1回で写せる。
  - 枠の上下の端をつかんで長さを変えられる。枠を押すと、時刻・ラベル（朝／電車／昼休み／塾のあと／自習室）・毎週くり返す・この日だけ休み・消す。
  - その週の登録がまだなら、上に案内が出る。
- 講師が入れた学習がカレンダーに出る（科目の色。終わったものは色を抑えて✓）。
- 上に**面談の予約欄**（4.6）。
- 週の合計：勉強できる時間／先生が入れた学習の時間。

### 4.4 記録
- 上の数字：今週の勉強時間（曜日ごとの棒、何件中何件完了）／これまでの合計（日数・件数）／今日（何日続けて勉強中か）。
- **参考書の進み**（参考書ごとに大きく出す。受験生にとって一番大事な情報という依頼者の判断）
  - 何範囲中いくつ済んだか・何％。
  - 進みの棒：青＝済み、**今日の目安**の位置に細い線、目安に届いていない分は薄い赤の斜線。
  - 今日の目安（あと何範囲）／目標（いつまでに1周）／このペースだといつ1周するか。
  - 状態：順調（色を付けない）／やや遅れ（橙）／遅れ（赤）／1周完了。
  - 範囲ごとのマス：済み／60%未満／予定あり／まだ の4種類。マウスを乗せると範囲名と点数・回数。
- **点数とひとこと**の一覧（教材で絞り込める）。コーチの返信もここに出る。
- 今週の教科ごとの勉強時間。

### 4.5 AI相談（受験AI Actifyくん）
- チャット画面。よく聞く質問がボタンで並ぶ：今日なにからやる？／参考書、間に合う？／苦手なところは？／覚え方のコツは？／やる気が出ない／問題の解き方を聞きたい。
- 問題の写真を送れる（**読み取りは未接続**。モックでは「まだ画像を読めない」と答える）。
- 答えはモックの中のデータから作った決まった文（**本物のAIは未接続**）。今日の残りの予定、参考書ごとの進みとこのペースでの終わる日、点の低い範囲とその時の一言、などを返す。
- **相談の内容は講師に共有しない**（画面にも明記）。
- パソコンでは、どの画面でも右下のActifyくんを押すと小さな相談の窓が開く。スマホではAI相談の画面へ移る。

### 4.6 面談の予約
- 講師が公開した「面談できる時間」から、**その週の1回を前日までに**生徒が予約する（毎週固定ではない）。
- 予約欄はおすすめの1つを大きく出す（順番：先週と同じ時間 → 自分の勉強できる時間と重なる所 → 週末）。ほかの時間はたたんである。
- 予約後は「時間を変える」（前日まで）／「カレンダーに入れる」（.ics ファイル。GoogleカレンダーやiPhoneのカレンダーに取り込める）。
- 当日は変更できない（「先生に連絡してください」）。終わった面談は「終わりました」。
- 講師が受付を止めているときは「先生が予約の受付を始めるのを待っています」。

### 4.7 資料
- 講師が配った資料（PDF）の一覧。全員向けと、その生徒だけ向けがある。
- 小テストの問題・解答は資料ではなく、ホームの予定から開く。

### 4.8 目標・プロフィール
- 左下の名前（パソコン）や「志望校まで◯日」を押すと出る。第一志望（大学・学部）、入試日とあと何日、参考書ごとの「いつまでに1周」。
- 目標は面談で先生と一緒に決める（生徒は画面から変えない）。

## 5. 講師の機能

### 5.1 生徒（講師のホーム）
- 担当の生徒を1人1枚で並べる。**対応が必要な順**に並ぶ。
- 1枚に出るもの：名前・学年・志望校まであと何日／次の面談（未予約なら橙）／気になる点（下の表）／今週の予定の完了数／来週の計画の量と空き時間／参考書ごとの進みの棒と状態／いちばん新しい生徒の一言。
- 気になる点（自動で出る）：

| 表示 | 条件 |
| --- | --- |
| 記録が◯日ない（赤） | 最後に完了した日から3日以上。一度も無ければ「まだ記録がない」 |
| やり残し◯件（赤） | 今週の過去の未完了 |
| 小テスト不足◯件（橙） | 予定に付けられる版が無い／2週間以内の再テストに使える版が無い |
| 来週の勉強できる時間が未登録（橙） | 生徒が来週の時間をまだ登録していない |
| 来週の計画がまだ | 来週の空き時間に対して入れた予定が3割未満 |

- 1枚を押すと、その生徒の計画画面へ。

### 5.2 計画（このサービスの中心）
左に週カレンダー、右（スマホは下から出るシート）に操作の欄。

**基本の流れ：空きを押す → 右で入れる**
- 「空き」＝生徒の勉強できる時間のうち、まだ何も入っていない所。カレンダーに「空き 45分」のように出る。
- 押すと右に、その時間のまとまり（例：10/5（月）06:00〜06:45 朝）が開く。‹ › で前後の時間へ送れる。
- 入っている予定の一覧（時刻・題名・初回／再テスト／やり残し／時間だけ・小テストの有無）。−／＋で5分ずつ長さを変える、×で外す（後ろは詰める）、題名を押すと詳しく直せる。

**入れ方（既定は講師が自由に入れる。おすすめは押したときだけ）**
1. **自由に書く**（いちばん上の既定）
   - 「模試の直し」と書けば、時間だけ取る予定。
   - 「ターゲット 801」と書けば、その参考書の範囲に結びつき、小テストも付く。「古文」だけなら次の範囲、済んだ範囲なら再テスト、予定に入っている範囲ならここへ移す。書いた瞬間にどう入るかが下に1行で出る。
   - 押すだけのボタン：予備時間／模試の復習／学校の課題／苦手の復習。
2. **教材を選ぶ**（タブで担当の参考書、プルダウンでほかの教材）
   - 範囲のプルダウン（✓済・●予定あり・再テストの時期・前回の点数つき）。最初は次の範囲。
   - 小テスト「第○版を付ける」のチェック（外せば付けない）。
   - 長さ：残りの時間に合わせた既定。15分〜残り全部から選べる。下に「この生徒はいつも約○分（直近5回）」。
3. **おすすめから入れる**（たたんである）：開くと中身の一覧（例：古文単語 101–150・再テスト・時期が来た・前回65%）と「この○件を入れる」。

**カレンダーでの直接の操作**
- 予定をつかんで別の日・時刻へ動かす。下の端を引っぱると終わり、上の端で始まりを変える（5分刻み、つかんでいる間は時刻が出る）。
- 空いている所をドラッグ（クリック）しても予定を追加できる。
- 予定や範囲にマウスを乗せる（スマホは長押し）と、その教材への**生徒のコメント**が小さな窓に出る。
- 「勉強できる時間を直す」で、講師が生徒の時間を代わりに直せる（生徒の画面にも出る）。
- 生徒の来週の時間が未登録なら「先週と同じで仮に入れる」「時間を直接入れる」の案内。
- 金・土・日に開くと**来週**から表示する（週末に翌週を組む前提）。

**右の欄のタブ**
- 予定を入れる（上の内容）
- **コメント**：教材ごとにたたんだ生徒の一言（件数と多い種類、未返信の数）。「返信」を押して書くと、生徒の「記録」に出る。
- **目標・メモ**：志望校・入試日／参考書と「いつまでに1周」の日付（追加・外す）／次の面談／生徒へのメッセージ（生徒のホームに出る）／講師メモ（生徒には見えない）。

**予定を直すダイアログ**：日付・開始・長さ（15〜90分のボタンと数字）・教材（教材なしも可）・範囲・小テストの版・削除。「追加して次の範囲も」で続きを続けて入れられる。

### 5.3 面談
- 講師の週カレンダーに**面談できる時間**をなぞって塗る（週ごと。先週と同じにもできる）。
- 1回の長さ：20／30／45／60分。
- **予約の受付**のオン・オフ（オフでも入っている予約はそのまま）。予約リンクのコピー。
- 右に、その週の生徒ごとの状態：予約済み（時刻・変更）／未予約（「土 14:00で入れる」のおすすめボタン。先週と同じ時間なら「先週は土 14:00」）／終わった面談は「済み」。
- 「未予約の○人をまとめて入れる」。
- 「カレンダーに書き出す」（.ics。テキストのコピーとファイル保存）。
- 面談の時間には学習を入れない（計画の空きから外れる）。講師は当日でも時間を変えられる。

### 5.4 小テスト
タブが2つ。

**問題・解答のPDF**
- PDFを何冊分でもまとめて置く（ドラッグか選ぶ）。問題と解答が混ざっていてよい。
- **ファイル名から 教材・範囲・問題か解答か を読み取る**（例：`ターゲット1900_201-300_問題.pdf`）。同じ範囲の問題と解答は1つの版にまとめる。版の番号は自動。
- 登録の前に確認の表（教材・範囲・版・満点）。読み取れなかったファイルだけ選ぶ。登録すると、小テストが無くて待っていた予定に自動で付く。
- **小テストが足りません**の一覧（どの生徒のどの範囲か、予定か再テストか）。
- **配った記録**の表：教材ごとに、範囲 × 生徒で「解いた版✓／予定に付いている版／次に配る版／配れる版がない」。
- 「サンプルのファイルで試す」で動きを試せる。

**配る資料**：ファイルを置くと、選んだ相手（全員か特定の生徒）の「資料」にすぐ届く。取り下げもできる。

## 6. 運営の機能

### 6.1 教材
- **目次ページの写真をまとめて置く**（1枚1冊）→ 文字を読み取って範囲の一覧にする → 確認して登録。**文字の読み取りは未接続**（同梱のサンプル画像2枚だけ中身を返す）。
- Excelの表から貼り付け（「教材名」「範囲」の2列）でもまとめて登録できる。
- 確認の画面で、教材名・科目・種類（インプット／演習）・目次（1行＝1範囲）を直せる。
- 登録済みの一覧：教材・種類・範囲の数・小テストが登録された範囲の数・使っている生徒の数。
- 行を押すと右から詳細：教材名・略称・科目・種類・再テストの間隔（日。例 1, 7, 30）・目次の写真と範囲の一覧（目次を直す）・小テストの登録状況・使っている生徒・削除（使われていない教材だけ）。
- 予定や小テストで使っている範囲は、目次から消せない（名前は直せる）。

### 6.2 アカウント
- 一覧（名前・役割・学年や担当・状態）と追加。
- 「変更」で役割（生徒／講師／運営／保護者）と状態（在籍／休会／退会）を変える。退会にすると講師の担当一覧から外れる。
- **ログイン・権限は未接続**（モックでは役割を上のボタンで切り替えるだけ）。保護者の画面は無い。

## 7. 受験AIキャラクター「Actifyくん」

- 白いヘルメットに青い顔の画面（目と口が水色に光る）のロボットのキャラクター。依頼者が用意した絵を使っている。
- 生徒の画面にだけ出る。画面を歩き回り、画面ごとに一言話す。
- 絵：表情・ポーズ・歩きの絵が全部で92枚。依頼者からもらった絵を Real-ESRGAN（アニメ絵向けの公開モデル、BSD-3-Clause）で4倍に高画質化して切り出した。
- ふだんの立ち姿は「目と口を消した体の絵」の上に、目と口をプログラムで描いている。まばたき・目がカーソルを追う・話すと口が動く。表情は 普通・笑顔・ウインク・考える・困る・眠る・びっくり など。
- ひとりのときの動き：歩く・走る・のんびり歩き・教材を運ぶ・虫めがねで探しもの・勉強してひらめく・考える・目標の旗（実際の志望校とあと何日）・メガホンで今日の残りの予定を知らせる・ひと休み・こんがらがる・ダンス・あくびして眠る、など。同じ動きは続けない。何もしない時間は4〜12秒。
- さわったときの反応：
  - なでる（頭の上でカーソルや指を左右に動かす）→ 喜ぶ → 照れる → 長くなでると眠る。
  - 押す → パソコンでは相談の小窓が開く。
  - 押しすぎる → 困る → 怒る → すねる → 泣く。なでると仲直り。
  - つまんで動かせる。振り回すと目を回す。
  - 30秒さわらないと眠る。
- 完了したときは点数で喜び方が変わる（80%以上：紙吹雪、60〜79%：ばんざい、60%未満：励まし）。
- 「隠れる」で隠せて、右下のボタンで呼び戻せる。

## 8. 決まりごと（計算・判定のルール）

### 8.1 教材
- 教材は**目次の範囲（ノード）の並び**でできている。例：英単語ターゲット1900 は 001–100 〜 1801–1900 の19範囲。
- 種類は2つ：
  - **インプット**（覚える教材。単語・古文単語など）：点数から再テストの時期を出す。
  - **演習**（解く教材。長文・数学など）：再テストは出さない。前回7割未満なら「解き直し」として計画のおすすめに出る。
- 再テストの間隔は教材ごと（例：英単語 1・7・30日、古文 1・3・7日）。
- 「1回の時間」は教材では決めない。**その生徒のその教材の実績（直近5回の平均）**から決める。実績が無ければインプット30分・演習45分。

### 8.2 再テストの時期
- 点数が付いた範囲について、やった回数 k に応じて間隔を選ぶ（1回目のあとは1つ目の間隔、2回目のあとは2つ目…）。
- 間隔を一通り終えて6割取れたら定着とみなし、もう出さない。
- 講師が「見送り」にした回は出さない。

### 8.3 小テストの版
- 1つの範囲に複数の版（第1版、第2版…）を登録できる。
- **同じ生徒に同じ版は二度付けない。** 「付いている」＝解いた、または予定に入っている。この判定はタスクに付いた版だけを見る（別の記録を持たない。重複を1か所で防ぐため）。
- 予定を入れると、その生徒がまだ使っていない版が自動で付く。版が尽きたら「小テスト不足」に出て、新しい版が登録されると待っている予定に自動で付く。

### 8.4 参考書の進み
- 済み＝その範囲を1回でも完了した。
- **今日の目安**＝全範囲 ×（開始日から今日までの日数 ÷ 開始日から目標日までの日数）。
- **このペースだと**＝直近3週間に初めて済ませた範囲の数から週あたりの速さを出し、残りを割って1周する日を出す。
- 状態：その日が目標日以前なら順調、14日以内の遅れならやや遅れ、それより後は遅れ。

### 8.5 範囲の順番がずれない仕組み
- まだやっていない1周目の予定は、**入れた順ではなく日付の順**に範囲の番号がそろう。例：先に土曜に「801–900」を入れ、あとで火曜に足すと、火曜が 801–900、土曜が 901–1000 になる。
- やり残しを後ろへ動かしたとき・カレンダーで前後を入れ替えたときも同じ。そろえたときは通知で知らせ、小テストの版も付け直す。

### 8.6 計画のおすすめ（おすすめから入れる）
- 入れたい順：再テスト（時期が来たもの）→ やり残し → 参考書の次の範囲 → 演習の解き直し（前回7割未満）→ 先取り。
- 参考書の次の範囲は「目標日から逆算した今週の必要数＋1」を週の中にならして出す。それを超えた分は「先取り」として後回し。
- 45分以下の短い枠（朝・電車）は覚える教材を優先。同じ日に同じ教材が続かないようにする。
- 空きの長さにぴったり入るように組み合わせと長さを決める（いつもの時間の0.8〜1.5倍、5分単位）。
- 枠の中は、考える演習を先、覚えるもの（単語・再テスト）を後に並べる。夜に覚えてそのまま眠ると残りやすいという研究に基づく（Gais ほか, 2006, *Learning & Memory* 13:259–262）。
- おすすめは**明日以降の空き**にだけ出す。予定と予定のあいだの休憩は自動では空けない。
- 勉強できる時間の外にも予定は置ける（注意の印だけ出る）。

### 8.7 面談
- 予約は前日まで。当日の変更は先生に連絡（講師の画面からは変えられる）。
- 候補の順：先週と同じ時間 → 生徒の勉強できる時間と重なる所 → 金・土・日。
- 面談の時間には学習を入れない。
- 勉強できる時間・面談できる時間はどちらも**週ごとの登録**。「毎週くり返す」は枠ごとに選べる例外。

### 8.8 そのほか
- 「今週の予定 ○/○件 完了」の分母＝今日までの予定と、先に済ませた予定。
- 生徒のAI相談の内容は講師に共有しない。
- 生徒の一言は講師の計画画面に届き、講師の返信は生徒の「記録」に出る。
- 講師のメッセージは生徒のホームに出る。講師メモは生徒に見えない。
- 金額の扱いは無い（料金・決済の機能はモックに無い）。

```
運営：教材（目次）
   ├─→ 講師：小テスト（PDFのファイル名の振り分け先・配った記録の行）
   └─→ 講師：計画（参考書の範囲）→ 生徒：記録（参考書の進み）

```

## 12. 見た目と使いやすさの決まり

依頼者は「AIが作った感じ」（角の丸いカードを並べる、キラキラのアイコン、絵文字、言い訳のような説明文、意味の分からない言葉）を強く嫌う。以下を守っている。

- **カードで囲まない。** まとまりは1pxの線と余白で区切る。背景は白。枠で囲むのは「次の予定」・カレンダー・チャット・講師の右の欄・面談の予約欄だけ（四角、影なし）。
- 角の丸み：まとまり 0 ／ ボタン・入力欄・ダイアログ 4px ／ タグ 2px（IBM の Carbon Design System の「角は基本 0、一部の部品だけ小さく丸める」考え方に寄せた）。丸いのは顔写真・完了のチェック・スイッチ・件数のバッジだけ。
- 文字の大きさは 12／14／16／20／24／32px の6段階、太さは 400／600／700 の3段階。
- 色は役割で決める：青＝押せる・選んでいる、緑＝勉強できる時間・完了、橙＝注意、赤＝対応が必要。科目ごとの色もある。ロゴの色は濃紺 #0c2a66・青 #1c64f2。
- 薄い灰色の文字もコントラスト比 4.5 以上（WCAG AA）。
- スマホの入力欄は16px（iPhoneで押したときに画面が拡大されない）。
- 日本語の改行：Google の BudouX（Apache-2.0）で文節の切れ目を入れ、語の途中で改行しない。「土 14:00」のように離したくない所は改行しない空白でつなぐ。
- 時間は「3時間54分」（小数の「3.9時間」は使わない）、期間は「9/28〜10/4」。
- スマホのダイアログは下から出るシートで、保存などのボタンは常に下に見える。
- **言葉づかい**：ネットで普通に使われる言葉を使う。造語・カタカナの専門用語を作らない（例：「計画に置く」より「予定を入れる」、「プリント」は「小テスト」にそろえた、「.ics」は「カレンダーに書き出す」）。
- 自動テストで確認：全11画面 × パソコン（1440px）・スマホ（390px）でエラー0・横のはみ出し0、axe-core（WCAG 2.1 A/AA）の違反0。
