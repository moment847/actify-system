## v19：角丸のカードをやめて線で区切る・全画面と全ダイアログを検証して直した

### 角丸のカードをやめた
- 白い角丸の箱を並べるのをやめ、まとまりは**1pxの線と余白**で区切る形にした（背景も白一色）。
- 角の丸みは IBM の Carbon Design System の考え方に寄せた（角の既定は 0、一部の部品だけ 2〜4px）：まとまりは 0、入力欄・ボタン・ダイアログは 4px、タグは 2px。
- 枠で囲むのは「今やること」（ホームの次の予定）・カレンダー・チャット・講師画面の右の欄・面談の予約欄だけ。四角の枠で、影は付けない。
- 丸い形が残るのは、顔写真・完了のチェック・切り替えスイッチ・件数のバッジだけ。進みの棒も角を落とした。

### ダイアログ
- スマホでは画面の下から出るシートにした。中身が長くても「保存」「完了にする」などのボタンは常に下に見える（以前は予定を直すダイアログの保存ボタンが画面の外に出ていた）。
- 開いた直後に × ボタンへ青い枠が出ていたのを直した（入力欄の指定が無いときは本文にフォーカスを置く。Tab キーで順に進める）。
- スマホでは開いた瞬間にキーボードを出さない（点数の入力欄に自動で入らない。キーボードでシートの半分が隠れるため）。
- 予定を直すダイアログの「時間」の数字欄に「分」を付けた。教材の略称のラベルを短くした。教材の引き出しをスマホで画面いっぱいにした。

### 文言の間違い
- 講師が過去の面談を開くと「前日を過ぎているので、変更は先生と相談してください」と出ていた（講師本人に「先生と相談」）。終わった面談は「この面談は終わっています」、講師は当日でも時間を変えられるようにした。
- 生徒の面談欄でも、終わった面談は「終わりました」と出す。講師の予約一覧では終わった面談に「済み」を付け、「変更」ボタンを出さない。
- 「未予約（先週は 土 14:00）」が狭い欄で途中から折り返していたのを、2行に分けた。
- 記録が一度もない生徒に「記録が—日ない」と出ていた（ダッシュが漢数字の「一」に見える）。「まだ記録がない」に直した。
- 今日の予定が0件の日に「今日の予定は0件、のこり0件です」「今日の予定はすべて終わりました」と出ていた。「今日は先生が入れた予定がありません」に直した（Actifyくんの一言も同じ）。
- 面談できる時間が登録されていない週に、全員「予約できる時間がもうありません」と出ていた。「面談できる時間がまだありません」に直した。

### アクセシビリティ（axe-core 4 で WCAG 2.1 A/AA を検査。全11画面・PCとスマホ・主なダイアログで違反0件）
- ホームの「早稲田大学まで◯日」は押せるのに div だったのを button にした（キーボードで押せる）。
- 終わった予定・過去の予定の文字が薄すぎた（コントラスト比 3.8〜4.0）。半透明をやめ、色を抑える形にして 4.5 以上にした。
- AI相談の「写真を送る」がキーボードで選べなかったのを直した。講師の「入れる」欄の教材の切り替えに押した状態（aria-pressed）を付けた。
- 指で押す端末では、文字だけのリンク（「解答を開く」など）の当たり判定を上下に広げた（見た目は変えない）。

## v18：Actifyくんの絵を高画質にして、全部使う・動きを増やす

### 絵
- いただいた2枚（表情・ポーズ32枚、追加のポーズ40枚）と、歩き20コマの絵を使っています。後ろ姿は、作り直していただいた2本足の絵に差し替えました。全部で92枚です。
- 高画質化は Real-ESRGAN（アニメ絵向けのモデル RealESRGAN_x4plus_anime_6B、BSD-3-Clause）で4倍にしました。そのあと800×800に切り出しています（以前は600×600）。
- 背景の抜き方は、白いヘルメットの輪郭の細い切れ目をふさいでから外側だけを透明にする方法です。2枚目のいちばん下の段は小さく描かれているので、顔の画面の大きさでほかの段とそろえました。
- ふだんの立ち姿（まばたき・目がカーソルを追う・話すと口が動く）は、高画質にした絵から目と口だけを消した体です（立つ・手を胸に・ばんざい・考える・指さす の5種類）。描き足す目と口は、元の絵の両目の位置から傾きと大きさを測って重ねています。
- 作り方の手順は `tools/` にあります（esrgan.py → run_cut.py → body.py）。

### 改行
- 日本語は、ブラウザの初期設定では1文字ごとに改行するため、「遅れ気｜味」「再テ｜スト」のように語の途中で切れていた。
- CSS の `word-break: auto-phrase` は iPhone の Safari が対応していない（2026年10月時点）。そこで Google の BudouX（Apache-2.0）の日本語モデルを `js/phrase.js` に同梱した。
- 画面に入る文字に文節の切れ目を自動で入れ、`word-break: keep-all` で切れ目と空白でだけ改行する。外部への通信はない。
- 「土 14:00」のように離したくない所は、改行しない空白でつないだ。

## v16 で変えたこと

### 角と影を、公開されているデザインシステムの尺度にそろえた
- 参考にした尺度：Material 3 の shape scale（入力欄 4 / チップ 8 / カード・ダイアログ 12 / シート 28）、デジタル庁デザインシステム（部品ごとに角丸を決め、小さい部品ほど小さく）、iOS の inset grouped リスト（約10pt・影なし・1pxの区切り線）
- 変えたこと：カード 16→10px（スマホ 8px）・ボタン 8px・入力欄 4px・チップとタグ 4〜6px（丸いピルをやめた）・吹き出し 12px・ダイアログ 12px。ぼかした影をやめ、1pxの線だけ。ボタンのグラデーションをやめて単色に

### AI相談
- 大きな絵の下に会話があって会話が隠れていたのを、スマホでは「1行のヘッダー＋会話が画面いっぱい」に。質問のボタンは入力欄のすぐ上に横並び
- スマホでは、Actifyくんを押したときも「AI相談」の画面に行く（浮いていた小窓は使わない。キーボードを出したときにずれていた）
- 相談画面の大きな絵に顔が無かったのを直した（絵そのものを使う）

### Actifyくん
- 行動の間隔をあけた（何もしないで立っている時間 4〜12秒。前は 1.5〜5秒）。セリフを言う割合も下げた
- パソコンでの大きさを 260→220px に（いただいた絵は1コマ約170pxなので、大きく出すほどぼやける）



### Actifyくん
- 歩幅を大きくした（1歩ぶんの絵の動きに合わせて進む。前は足だけ動いて進まない「小股」だった）。走って横切ることもある
- 動きを追加：走る・大喜び（ジャンプ→ばんざい→紙吹雪）・たいくつ（→あくび→昼寝）・考えてひらめく・くしゃみ・つまずく・プレゼント・照れ・きょとん・話しかける・お知らせ
- セリフを増やした：豆知識 18種、ひとりごと 16種、時間帯のあいさつ（朝・昼・夕・夜・深夜）、いまの状況で変わる気持ち（やり残しがある／参考書が遅れている／今日ぜんぶ終わった／あと何件）、なでたとき・押しすぎたときのセリフも複数から
- 完了したときの喜び方が点数で変わる（80%以上：紙吹雪、60〜79%：ばんざい「あと少しで満点」、60%未満：「次はもっといける！」）。満点は特別なひとこと
- 長くなでると、なでられたまま眠る

### スマホ
- 全体を小さく：カード・文字・ボタン・余白・カレンダー（1時間 32px）・参考書のカード・予定の行・下のタブ
- 記録の上に「今週の勉強時間」「これまでの合計」「今日（何日続けているか）」「今週の毎日」をまとめて出した（パソコンでも同じ）

| **押しすぎ**（5秒のうちに何度も） | 2回目「ん？」→ 3〜4回目 困る「ちょ、ちょっと…」→ 5〜6回目 怒る「もう！さわりすぎ！」→ 7回目 背中を向けてすねる「ふんっ。しらない。」。すねている間にさらに押すと泣く。しばらくすると「…もうしない？」で仲直り |
| **すねている時になでる** | 「…なでてくれるなら、ゆるす。」で機嫌が直る |
| **つまんで動かす** | 両手でほっぺ（びっくり）。振り回すと目を回し、下ろすとふらふら「…ここどこ？」 |
| **寝ているときに押す・なでる** | 「わっ！ おきてる、おきてるよ！」 |

### ひとりのとき
- 歩く（20コマ。左へ行くときは向きを変える）・ぴょんぴょん跳ねる・見回す・のぞく・伸び・回る・踊る
- パソコンで調べもの・タブレットで予定を見直す・歌う・考える・手をふる・「がんばろう！」・ハート・豆知識（指さし・メガホン・吹き出し）
- 立ったままうとうと／寝そべって昼寝。30秒さわらないと寝そべって眠る（動かすと「わっ、おかえり！」）
- タスクを完了すると紙吹雪 → ばんざい
- 画面ごとの一言もポーズつき（予定：指さし／記録：遅れていれば「がんばろう」、順調ならばんざい／資料：プレゼント）

### 見た目のしくみ
- ふだん立っているときは、これまでどおり顔をプログラムで描く立ち絵（まばたき・目がカーソルを追う・話すと口が動く）
- 動き・表情のポーズは、いただいた絵。背丈と足元の位置を立ち絵にそろえてあるので、切り替えても大きさが変わらない（assets/sp/）

## v11 で変えたこと

### 生徒の勉強できる時間：週ごとの登録（毎週の固定をやめた）

- 講師の計画画面でも、来週の登録が無い生徒には同じ案内が出る（「先週と同じ時間で仮に入れる」「時間を直接入れる」）。講師のホームの札にも「来週の空き時間が未登録」が出る

### 講師の計画：自由に書くのが既定。おすすめはたたんである
- 空きを押すと、右に「何をする？」の欄が出る。書いて Enter で入る（時間は残りに合わせた既定。横で変えられる）
  - 「模試の直し」のように書けば、時間だけ取る予定
  - 「ターゲット 801」のように書けば、その参考書の範囲に結びつけて小テストも付く。「古文」だけなら次の範囲、「ターゲット 501」のように済んだ範囲なら再テスト。書いた瞬間に、どう入るかが下に1行で出る
  - 予備時間・模試の復習・学校の課題・苦手の復習 は押すだけ
- その下は3つにたたんである：**参考書の次の範囲**（参考書ごとのボタン）／**おすすめで埋める**（開くと中身の一覧と「この○件を入れる」）／**目次から選ぶ**。開いた状態は覚えておく
- 「週の空きをおすすめで埋める」は無くした（たたんだ「おすすめで埋める」を時間ごとに使う）

### タスクの引き伸ばし・移動（ドラッグ）

- 予定そのものをつかんで別の日・時刻へ動かすのは従来どおり

### 面談：固定ではなく、その週の1回を前日までに予約
- 講師は「面談できる時間」を週ごとに塗る（先週と同じにもできる）。1回の長さを選んで公開
- 生徒の「予定」の上に、今週・来週の面談の欄。おすすめ（先週と同じ時間 → 勉強できる時間の中 → 週末）を1回押せば予約。前日まで変えられる（当日は変更不可・先生に連絡）

- 画面の左端にいるときも吹き出しが切れないようにした

## v10 で変えたこと

いただいた指摘：「基本はコーチが自由に入れる。おすすめはボタンで」「先に入っている感じが操作しにくい」「どこから入れるかで進みの前後が狂わないように」「予備時間・模試の復習のような漠然とした時間も」「講師のカレンダーを公開して、生徒が週1回自動で予約」「タイマーを途中で止めたい・時計の形に」

### 講師の計画：先生が自由に入れる（おすすめはボタンを押したときだけ）
- 空きを押すと、右にその時間（勉強できる時間のまとまり）が開く。最初は空っぽ。先に案が入っていることはない
- 入れ方は4つ。どれも押した瞬間にカレンダーに入る（取り消しは下の通知から）
  1. **参考書の次の範囲**：参考書ごとのボタン。入る範囲と長さがボタンに書いてある
  2. **時間だけ取る**：予備時間・模試の復習・学校の課題・苦手の復習・自由に書く。内容はあとで決めてよい
  3. **おすすめで残りを埋める**：押す前に、何が入るかを一言で出す（例：再テスト 古文　やり残し 古文…）
  4. **範囲を選んで入れる**：目次から（再テスト・先の範囲も）
- 長さは残りの時間に合わせる（残りが短ければいっぱいに、長ければいつもの時間）。一覧の −／＋ で5分ずつ変えられ、× で外すと後ろが詰まる
- カレンダーで予定を押すと、その時間が右に開く（一覧の題名を押すと、日付・範囲・小テストまで直せる）
- 「週の空きをおすすめで埋める」は右上に小さく残した（まとめて入れたいとき用）

### 範囲の前後がずれない
- まだやっていない1周目の予定は、**入れた順ではなく日付の順**に範囲の番号がそろう。土曜に「801–900」を入れたあとで火曜に足すと、火曜が801–900、土曜が901–1000 になる（ボタンにも「後ろを繰り下げ」と出る）
- やり残しを後ろへ動かしたとき、カレンダーで予定を前後に動かしたときも同じ。そろえたときは通知で知らせる
- 小テストの版も、入れ替わった範囲に合わせて付け直す（同じ生徒に同じ版は付けない、はそのまま）
- 目次から、もう予定に入っている範囲を選んだときは、二重に入れず「ここへ移す」を出す

### 時間だけ取る予定（予備時間・模試の復習など）
- カレンダーでは灰色の斜線で、ふつうの学習と見分けられる
- **予備時間**は、生徒のホームで「やり残しを入れる」ボタンになる（いちばん古いやり残しを、その時間に入れる）。「つぎはこれ」には出さない

### 面談：講師のカレンダーを公開 → 生徒が毎週1回を予約
- 講師メニューに「面談」。面談できる時間をカレンダーになぞって塗る（毎週くり返し）。1回の長さ（20／30／45／60分）を選び、予約ページを公開する
- 生徒の「予定」の上に予約の欄が出る。おすすめの時間（生徒の勉強できる時間と重なり、週末を優先）を1回押せば、**毎週自動で入る**。都合が悪い週は「この日だけ休む」
- 未予約の生徒は、講師が「自動で入れる」でまとめて入れられる
- 面談は生徒の予定・講師の計画のカレンダーにオレンジで出て、その時間には学習を入れない（空きから外れる）
- 「カレンダーに取り込む（.ics）」で、GoogleカレンダーやiPhoneのカレンダーに毎週の予定として入る（休みの週は抜く）

### タイマー：一時停止できる・時計の形
- 時計の文字盤で、色の部分が「あと何分」。1周＝60分（予定が60分を超えるときは120分）。予定を過ぎると「+○分 オーバー」
- 一時停止・再開・タイマーをやめる。止めていた時間は勉強時間に数えない

## v9 で変えたこと（講師の計画）

いただいた指摘：「タスクは、もとある長さに合う形で入るといい」「提案を見やすく」「認知負荷の問題」

### 1つの空きに、1つの判断
- 空き（勉強できる時間のうち、まだ何も入っていない所）を押すと、右に **「この枠に入れる案」** が出る。押すのは「○件を入れる」の1回だけ
- 入れたら、次の空きへ自動で進む。右の上の ‹ › でも空きを順に送れる（カレンダーに戻らなくてよい）

### タスクは枠の長さに合わせて入る
- 45分の朝の枠には45分ちょうど、3時間の夜の枠には3時間ちょうどになるよう、組み合わせと長さを決める
- 長さは「その生徒のその教材のいつもの時間（直近5回の平均）」を元に、枠に合わせて伸び縮みさせる（0.8〜1.5倍・5分単位）。半端な空きが残らない
- 案の一番上の色の帯が、枠の中の割り振り。カレンダーの枠の中にも同じ案が点線で出るので、入れたらどう見えるかがそのまま分かる

### 案を見やすく
- 1件は2行だけ：①開始時刻と長さ・教材と範囲・小テストの印　②理由（再テスト／やり残し／次の範囲／解き直し／先取り の札＋短い一言）
- 案から外すのは × 、足すのは下の「ほかの候補」を押すだけ。外す・足すと、時間は自動で配り直す
- 枠がいっぱいのときは、候補が「入れ替え」に変わる（優先度の低いものと入れ替える）
- 参考書の目次から自由に選ぶ・教材なしの学習（学校の課題など）は、いちばん下にたたんである

### 「空きを全部おすすめで埋める」
- 週の空きを、枠ごとに同じやり方でまとめて埋める（1回で取り消せる）

### 自由度はそのまま
- 候補をカレンダーへドラッグしても入る（空きの上に落とすと、枠の頭にそろえて長さを合わせる）
- 枠の外はドラッグ（クリック）で自由に追加。入れた予定は押せば直せ、下の端を引っぱれば長さを変えられる

```
講師：面談（週ごとに面談できる時間を公開）─→ 生徒：予定（その週の1回を前日までに予約）─→ 両方のカレンダー・.ics

講師：計画で予定を置く ─→ その生徒が未使用の版を自動で付ける ─→ 生徒：ホーム（問題・解答）
                                       └ 版が無ければ「プリントが足りません」に出る ─→ 講師：プリントで追加 → 待っている予定に自動で付く

生徒：完了（点数・ひとこと）
   ├─→ 再テストの時期（覚える教材だけ。1日後→7日後→30日後 など教材ごと）─→ 講師：計画の案
   ├─→ 生徒：記録（参考書の進み・点数）
   ├─→ 講師：計画（コメントの小窓・コメントタブ）─ 返信 ─→ 生徒：記録
   └─→ Actifyくん（今日の予定・進み・苦手を答える材料）
```

## 試す順番

1. 生徒「ホーム」：つぎはこれ →「始める」→「完了」→ 点数とひとことを入れる
2. 右下のActifyくん →「参考書、間に合う？」
3. 生徒「予定」：日曜の空いている所をなぞって、勉強できる時間を足す
4. 講師に切り替え →「生徒」で山田 陽菜のカード → 計画（金〜日は来週から開く）。月曜夜の空きを押す
5. 「何をする？」に「模試の直し」と書いて Enter → 教材のタブで「古文」→ 範囲のプルダウンで済んだ範囲（✓）を選ぶと「再テスト」、先の範囲も選べる → 小テストのチェック・長さを選んで「入れる」
5b. 「おすすめで埋める」を開いて「この○件を入れる」→ カレンダーの予定の下の端をつかんで引き伸ばす
5c. 生徒を佐藤 美咲に変える → 「来週の勉強できる時間が未登録」の案内 →「先週と同じ時間で仮に入れる」
5d. 講師「面談」→ 来週へ → 「まだの○人をまとめて入れる」。生徒「予定」の上で「この時間で予約」「時間を変える」
5e. 生徒「ホーム」のActifyくん：頭の上でカーソルを左右に動かしてなでる → 何度も押して怒らせる → すねたらなでて仲直り → つまんで振り回す
6. 右の「コメント」タブで返信 → 生徒の「記録」に出る
7. 講師「プリント」：「プリントが足りません」を確認 →「サンプルのファイルで試す」→ スキャン_0012.pdf の範囲を選ぶか外す → 登録
8. 運営「教材」：「サンプルの目次で試す」→ 登録 → 一覧の行を押して詳細

## 決めたこと（違えば直します）

- 再テストは「覚える教材（インプット）」だけ。点数が付いた範囲について、やった回数に応じて教材ごとの間隔で時期を出す。間隔を一通り終えて6割取れたら出さない
- 金・土・日は講師の計画画面を「来週」から開く（週末に翌週を組む前提）
- 案は「明日以降の空き」にだけ出す
- 案に入る順番：再テスト（時期が来たもの）→ やり残し → 参考書の次の範囲 → 演習の解き直し（前回7割未満）→ 先取り。同じ枠に同じ教材は、ほかに入れるものが無いときだけ
- 参考書の次の範囲は「目標日から逆算した今週の必要数＋1」を週の中にならして出す。それを超えた分は「先取り」として後回し
- 45分以下の短い枠には、覚える教材を優先（演習は後回し）
- 枠の中は、考える演習を先、覚えるもの（単語・再テスト）を後に並べる。夜に覚えてそのまま眠ると、朝に覚えるより残りやすいという研究があるため（Gais ほか, 2006, *Learning & Memory* 13:259–262）
- 長さの伸び縮みは0.8〜1.5倍まで。それでも枠が余るときは「残り○分は空きのまま」と出す
- 予定と予定のあいだに休憩の5分は自動では空けない（空きの長さにぴったり入れるため）。休憩を取りたいときは −／＋ で調整
- 面談の候補は、先週と同じ時間 → 生徒の勉強できる時間と重なる所 → 金・土・日（1週間をふり返って翌週を組める日）の順
- 面談の予約は前日まで。当日の変更は先生に連絡（画面からは変えられない）
- 面談の時間は勉強できる時間の中でも学習を入れない
- 勉強できる時間・面談できる時間は週ごとに登録。「毎週くり返す」は枠ごとに選べる例外
- 勉強できる時間の外にも予定は置ける（点線の枠で注意だけ出す）
- 1つの範囲のプリントは同じ生徒に二度配らない。版が尽きたら新しい版の登録を待つ
- AI相談の内容は講師に共有しない
- 「始める」から5分未満で完了したときは、押し間違いとみなして予定の時間で記録

## 制約（モック）

- HTML / CSS / JavaScript のみ。ログイン・権限・サーバ保存はなし
- 目次画像の文字の読み取り、Actifyくんの返答、問題写真の読み取りは未接続（サンプルの目次画像だけ中身を返す。返答はアプリ内のデータから作った決まった文）
- アップロードしたファイルは1.5MBまでブラウザに保存。それ以上はページを閉じるまで有効
- 初期のPDFは操作確認用の共通サンプル
- これまでの記録はデモ用に自動で作ったもの
